# Prodigy InfoTech – Data Science Internship Task 03

## Decision Tree Classifier

### Objective
Build a Decision Tree Classifier to predict whether a customer will purchase a product or service based on their demographic and behavioral data using the Bank Marketing dataset.

### Dataset
Bank Marketing dataset provided through the Prodigy InfoTech Task 03 repository.

### Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

### Work Done
- Loaded and inspected the Bank Marketing dataset
- Performed data cleaning and preprocessing
- Analyzed the target variable
- Encoded categorical variables
- Split the dataset into training and testing sets
- Built and trained a Decision Tree Classifier
- Evaluated the model using accuracy and classification report
- Created a confusion matrix
- Visualized the decision tree
- Analyzed feature importance

### Key Learnings
- Understanding supervised machine learning
- Building classification models
- Encoding categorical features
- Splitting data into training and testing sets
- Evaluating classification model performance
- Understanding decision tree predictions
- Analyzing feature importance

### Conclusion
A Decision Tree Classifier was successfully built to predict customer subscription behavior using the Bank Marketing dataset. This task provided practical experience in data preprocessing, classification, model evaluation, visualization and feature importance analysis.
